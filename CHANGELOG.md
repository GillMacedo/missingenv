## [0.1.0] - 2026-11-01

### Added
- Reads env var names from Go, Python, JavaScript, TypeScript, Ruby, Java, Kotlin, Rust and PHP code.
- Compares them with Dockerfile, Compose, Kubernetes, ConfigMap and example env files.
- Text, Markdown and JSON output, `--fail-on` and `--ignore`.
- `checking-env-config` skill and plugin manifest.
